# Kakeibo 要件定義書

## 1. ドキュメント概要

| 項目 | 内容 |
|---|---|
| アプリ名 | Kakeibo（仮称） |
| ドキュメント | 要件定義書 |
| 対象 | 20〜30代の一人暮らし会社員 |
| 目的 | 家計管理の効率化とWebアプリ開発スキルの習得 |
| 対象フェーズ | MVP（最小限の実用的な製品） |

## 2. 背景・課題

家計管理を行う際、以下の課題がある。

- 毎月どのくらい支出しているのか把握しづらい
- 食費や日用品など、カテゴリ別の支出が分かりづらい
- 支出を登録する操作が多いと、入力を継続できない
- 月末にならないと収支状況を把握できない

## 3. サービスの目的

日々の収入・支出を簡単に登録でき、月ごとの収支や支出傾向を直感的に把握できる家計簿Webアプリを提供する。

また、要件定義から設計、実装、テスト、デプロイまでを経験し、React・TypeScript・Next.jsを中心としたWeb開発スキルを高める。

## 4. ターゲットユーザー

- 20〜30代の会社員
- 一人暮らしで家計を管理したい人
- 毎日の入力をなるべく簡単に済ませたい人
- 月ごとの収支や支出内訳を確認したい人

## 5. 基本方針

1. 支出登録の操作をできるだけ少なくする
2. スマートフォンでも操作しやすいUIにする
3. 収支状況を金額とグラフで分かりやすく表示する
4. ユーザーごとにデータを分離する
5. MVPでは必要な機能に絞り、将来的に拡張できる構成にする

## 6. 機能要件

### 6.1 認証

- ユーザー登録
- ログイン
- ログアウト
- 認証状態の確認
- 未認証ユーザーによる保護画面へのアクセス制限

### 6.2 支出管理

- 支出の登録
- 支出一覧の表示
- 支出詳細の表示
- 支出の編集
- 支出の削除
- 日付・カテゴリ・金額・メモの管理

### 6.3 収入管理

- 収入の登録
- 収入一覧の表示
- 収入の編集
- 収入の削除

### 6.4 カテゴリ管理

- カテゴリ一覧の表示
- カテゴリの追加
- カテゴリ名・アイコンの編集
- カテゴリの削除
- 収入カテゴリと支出カテゴリの区別

### 6.5 ダッシュボード

- 指定月の収入合計
- 指定月の支出合計
- 指定月の収支
- カテゴリ別支出合計
- 支出内訳のグラフ表示
- 表示対象月の切り替え

### 6.6 入力補助・状態表示

- 金額や必須項目のバリデーション
- 登録処理中のローディング表示
- 登録成功・失敗メッセージ
- データが存在しない場合の空状態表示

## 7. 非機能要件

### 7.1 セキュリティ

- パスワードを平文で保存しない
- 認証情報をサーバー側で検証する
- ユーザーごとのデータアクセスをサーバー側で制御する
- クライアントから送られた `userId` を信用しない
- 入力値をサーバー側でも検証する
- 秘密情報を環境変数で管理し、Gitに登録しない

### 7.2 ユーザビリティ

- スマートフォンとPCの両方で利用できる
- 支出登録画面では金額入力を目立たせる
- 必須項目と任意項目を明確にする
- エラーの原因と対処方法を分かりやすく表示する

### 7.3 保守性

- TypeScriptで型を管理する
- UI・業務ロジック・データアクセスの責務を分離する
- 共通処理を適切に再利用する
- ESLintなどの静的解析を導入する
- 重要な処理にテストを用意する

### 7.4 運用

- GitHubでソースコードと設計書を管理する
- 本番環境へデプロイする
- 環境変数を開発・本番で分離する

## 8. MVPの対象範囲

### 実装対象

- 認証
- 支出CRUD
- 収入CRUD
- カテゴリCRUD
- 月次ダッシュボード
- カテゴリ別支出集計
- 基本的なバリデーションとエラー表示
- テスト・デプロイ

### MVPでは実装しない機能

- 資産・証券口座の連携
- 銀行口座との自動連携
- レシート画像の読み取り
- 貯蓄シミュレーション
- 定期支出の自動登録
- 予算設定・予算超過通知

## 9. MVP完了条件

- [ ] ユーザー登録・ログイン・ログアウトができる
- [ ] 支出・収入を登録、参照、編集、削除できる
- [ ] カテゴリを管理できる
- [ ] 月ごとの収入・支出・収支を確認できる
- [ ] カテゴリ別の支出内訳を確認できる
- [ ] ユーザー間でデータが混在しない
- [ ] バリデーションとエラー表示が機能する
- [ ] 主要な処理のテストが実施されている
- [ ] 本番環境で動作する
